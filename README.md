 # Portfólio — Lucas Martins

 Breve portfólio pessoal estático construído com React e TypeScript, pronto para deploy e personalização.

 **Resumo**

 - Autor: Lucas Martins
 - Última atualização: 2024
 - Propósito: Apresentar projetos, habilidades e formas de contato

 **Linguagens e frameworks usados**

 - Linguagens: TypeScript, HTML, CSS
 - Framework: React
 - Bundler / Dev server: Vite
 - Estilização: Tailwind CSS
 - Animações: Framer Motion
 - Ícones: lucide-react

 **Estrutura principal do projeto**

 - `index.html` — entrada HTML principal
 - `src/main.tsx` — bootstrap do React
 - `src/App.tsx` — componente root
 - `src/components/*` — componentes do site (Hero, About, Projects, Contact, etc.)
 - `src/index.css` — estilos globais (Tailwind)

 ## Como rodar localmente

 1. Instale dependências:

 ```bash
 npm install
 ```

 2. Rode em modo desenvolvimento (Vite):

 ```bash
 npm run dev
 ```

 3. Build para produção:

 ```bash
 npm run build
 ```

 4. Visualizar o build localmente:

 ```bash
 npm run preview
 ```
